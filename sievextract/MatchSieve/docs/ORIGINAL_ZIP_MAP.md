This new project uses the old source as a design reference; it does not copy its `.git`, config key files, `__pycache__`, or partially working provider layer wholesale.

## Important secret hygiene note

The ZIP contains eight `config/*_key.txt` files with non-placeholder-looking strings and also includes the `.git` directory/history. This audit does not reproduce any of the values. The new project contains no copied key files. If the values were real, revoke/rotate them at the provider and check whether Git history/shared copies contain them. Use local `.env` variables, never tracked source files.

## How this new foundation connects later

The analysis engines should consume a stable `FixtureEvidence`-like object generated by the repository. They should not directly call external providers. First prove intake, provenance, history and report generation; then adapt each existing engine in one-by-one commits with offline regression tests. Do not add the old engine path to this UI until the required field contracts are documented and tested.
